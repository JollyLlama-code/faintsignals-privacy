RankMonk Privacy Policy

Last updated: 2026-06-03

RankMonk is a single-channel video-publishing tool operated by the owner of the YouTube channel @RankMonk1. It uploads the owner's own original videos to the owner's own channel.

What data we access

With the owner's Google authorization, the tool uses the YouTube Data API to (1) upload videos to the owner's channel (youtube.upload) and (2) read the owner's channel title to confirm uploads target the correct channel (youtube.readonly). It accesses no other channel's data.

What data we store

An OAuth access/refresh token is stored locally on the owner's own devices to avoid repeated sign-in. No YouTube data is transmitted to, shared with, or sold to any third party. The tool collects no data from any end users.

Limited Use

RankMonk's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically, the data accessed via the YouTube Data API is used only to upload the owner's own videos and verify the destination channel. It is never used for advertising, never sold or transferred to third parties, never used to build profiles, and is never read by humans except the channel owner.

Data retention and deletion

Deleting the local token file removes the tool's stored access. The owner may also revoke access at any time at Google Account permissions. Google's handling of API data is governed by the Google Privacy Policy.
